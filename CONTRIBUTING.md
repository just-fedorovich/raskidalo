# Участие в проекте

## Лицензия
Проект под PolyForm Strict 1.0.0 — source-available, не open-source. Pull requests принимаются, мерж — по согласию владельца проекта.

## Процесс
1. Открой Issue и опиши предложение или баг.
2. Дождись обсуждения — во избежание работы «в стол».
3. Форкни репозиторий, сделай изменения на отдельной ветке.
4. Открой Pull Request со ссылкой на Issue.
5. Дождись review.

## Стиль кода
- Python 3.11+.
- Форматирование: `black` (line-length 100).
- Линт: `ruff`.
- Импорты: стандартная библиотека → сторонние → локальные, разделены пустой строкой.

## Smoke-тест перед PR
Перед отправкой PR убедись, что:
- Бот запускается локально согласно инструкции Этапа 1.
- `/start` в dev-боте (@RaskidaloDevBot) отвечает без ошибок.
- В Sentry не появилось новых Issue.

## Секреты
Никогда не коммить `.env`, реальные токены или DSN. Проверяй `git status` перед `git commit`. Файл `.env` в `.gitignore`, но `git add -f` может это обойти — не делай так.
