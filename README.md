## Как пользоваться

1. Открой бота: https://t.me/RaskidaloBot
2. Нажми /start и укажи свой город (текстом или геопозицией).
3. Добавь друзей по @username — дружба взаимная, по заявке.
4. Смотри «Где X?» и «Кто в городе Y?» — в пределах настроек приватности каждого.
5. Приватность: меню «⚙️ Настройки» — кто видит, что именно видно, режим невидимки.
6. Удалить аккаунт полностью: /deleteme.
